# 3DGame

This repository contains a 3D game project built in C++ with OpenGL tooling. The codebase is organized around a game engine and world-rendering pipeline, with project notes and game design documentation stored under the `Project/` directory.

## Repository purpose

- 3D rendering and world generation experiments
- OpenGL-based game engine work
- Project documentation for architecture, context, and AI notes
- A place to prototype gameplay systems and rendering features

## Current structure

- `Project/` – main project source and documentation
- `Project/Read/README.md` – project overview
- `Project/Read/AI_CONTEXT.md` – AI-related notes and context

## Tech stack

- C++17
- OpenGL 3.3 Core
- GLFW
- GLAD
- GLM
